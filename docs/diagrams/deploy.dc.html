실험 설계
두 패스의 파드 사양(이미지 · CPU · 메모리)은 전부 같다. 다른 것은 배치 하나 — 그래서 두 패스의 배수 차이가 곧 노드 분리의 순효과다.
하드웨어가 달라(4 vs 8 vCPU) 절대값 비교는 무효. 각 패스 안의 유휴 대비 배수만 비교한다.
실측 2026-07-26 · ADR 0011
벡터 재색인 중 앱 CPU 경쟁 — 노드 분리로 풀린다 ✅
1.09 → 0.90 차이 +0.19
색인 비용의 96%가 임베딩 추론 = 순수 앱 CPU. 색인기가 다른 노드로 빠지면 경쟁 자체가 사라져, 질의가 유휴보다도 빨라진다(0.90).
키워드 재색인 중 엔진 공유 경쟁 — 남는다 ❌
1.11 → 1.07 차이 +0.04
비용이 공유 Elasticsearch 의 _bulk — 색인기를 어느 노드에 놓든 질의가 쓰는 같은 ES 파드를 때린다. ADR 0002 의 클러스터 분리로만 풀린다.
